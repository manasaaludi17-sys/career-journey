## 2. Git and GitHub

Learned the difference between Git and GitHub.

### Git

Git is a Version Control System (VCS) used to track changes in my code.

### GitHub

GitHub is an online platform where I can store and manage Git repositories.

### Repository

A repository is a project that is tracked using Git.

### Basic Git Workflow

```text
Write Code
    ↓
git add .
    ↓
git commit
    ↓
git push
    ↓
GitHub
```

### Important Git Commands

```bash
git status
git add .
git commit -m "message"
git push
git pull
git log
```

## 3. Python — Step 1

### What is Python?

Python is a high-level, interpreted programming language.

Python is widely used for:

- Software Development
- Data Science
- Artificial Intelligence
- Machine Learning
- Automation
- Web Development

### Python File

Python programs normally use the `.py` extension.

Example:

```text
hello.py
```

### print()

`print()` is a built-in Python function used to display information on the screen.

Example:

```python
print("Hello, World!")
```

Output:

```text
Hello, World!
```

### Important Points

- Python is case-sensitive.
- `print()` displays output on the screen.
- Text inside quotation marks is a string.
- Python files normally have the `.py` extension.
